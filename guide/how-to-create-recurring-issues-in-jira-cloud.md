For a simple repeating task, start with Jira's built-in Automation: use a scheduled trigger and a Create issue action. If you need business-day dates that follow a holiday calendar, a per-schedule time zone, or a preview of the next 10 dates before saving, RepeatWise can create recurring Jira Cloud issues from a saved schedule.

## Choose a method and set up the schedule

1. **Try Jira Automation first.** Create a rule with a **Scheduled** trigger, add a **Create issue** action (called **Create work item** on some sites), and set the project, issue type and fields you need. Test the rule in your Jira site before relying on it. If you already have an issue with Jira's **Set to recur** option, that is another built-in route; see [Migrating to RepeatWise](migrating.html) before replacing it.
2. **Open RepeatWise if you need its scheduling options.** Find **RepeatWise** in the Jira apps menu or a project's sidebar, then select **New schedule**. By default, you need project administrator access and **Create issues** permission; an administrator can allow anyone with Create issues permission to make schedules.
3. **Use Quick Start.** Describe the work in one sentence under **What do you want to repeat?**, or switch to **Form**. Check **Issue**, choose a **Project**, then set **Repeat**, **Starts**, **Time**, and **Time zone**, and what happens **If previous issue is still open**. **Next runs** shows the next three dates. Select **Create schedule** when it is right. You can also pick one of the **Quick templates** to fill the form.
4. **Open the full wizard for more settings.** Select **More options** in Quick Start. In **What**, add a description, assignee, priority, or labels. In **When**, set a custom recurrence or end rule. In **Rules**, choose a holiday calendar and policy if needed. On **Review**, inspect the next 10 occurrences and example issue, then select **Save**. RepeatWise checks for due schedules every 5 minutes; the schedule owner is the reporter on created issues.

## FAQ

### Does Jira Cloud have a built-in way to repeat issues?

Yes. Jira Automation can create issues from a scheduled rule, and Jira's **Set to recur** option is available on issues in supported Jira experiences. Check which option your site offers before adding an app.

### Can I start from an existing Jira issue?

Yes. **Make this issue recurring** opens the RepeatWise wizard with supported fields filled in. RepeatWise stores a template; it does not clone attachments, links or child issues.

### What if I need a particular business day each month?

Choose a monthly position such as **Last business day**, then set the holiday country in **Rules**. See [Last business day and holidays](recurring-issue-last-business-day.html).
